Puzzle Solver

A 30×30 grid pathfinding visualizer. Pick a tool below, mark a start cell and an end cell, draw some walls, then hit Solve to watch a depth-first search explore the grid and trace the path it finds — DFS finds *a* path, not necessarily the shortest one.
